# URL Monitor

A small Python utility for checking whether a website or API endpoint is reachable.

## Features

→ Check URL availability  
→ Display HTTP status code  
→ Measure response time  
→ Handle connection errors  
→ Show the latest check time  

## Requirements

- Python 3.10+
- Requests

## Usage

```bash
python url_monitor.py
```

### Example
```text
=== URL Monitor ===

Target: https://example.com

Status     : ONLINE
HTTP Code  : 200
Response   : 0.42s
Checked at : 2026-09-04 12:45:21
```
